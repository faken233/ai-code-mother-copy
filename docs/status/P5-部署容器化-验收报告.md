> 完成时间：2026-10-24（Asia/Shanghai）

> 前置文档：`docs/status/交接-访问入口与双模式改造.md`、`docs/status/P4-工具通道与热更新-验收报告.md`

## 1. 一句话结论

部署不再往 `tmp/code_deploy` 复制文件、也不再由主服务托管静态资源：每次部署都会生成**不可变快照 + 生产镜像 `app-dep-{appId}:v{n}`**，跑一个只暴露应用端口的容器 `app-dep-{appId}-v{n}`，健康检查通过后才把 `{deployKey}.app.localhost:8124` 的路由原子切到新版本。回滚只需把路由指回上一个版本容器，**地址不变、生产库数据不动**。

## 2. 部署链路

```
deployApp(appId)
  ├─ 校验：本人应用 / static|fullstack / server.js 存在 / public-dist 已构建
  ├─ deployKey：首次随机 6 位小写，之后固定（地址永不变）
  ├─ 生产库：schema.tables 非空 → app_{appId}_prod（独立账号 + 稳定密码 + 稳定 JWT）
  ├─ 快照：tmp/code_deploy/{appId}/v{n}/（含 node_modules，构建不依赖网络）
  ├─ 镜像：docker build app-dep-{appId}:v{n}
  ├─ 容器：app-dep-{appId}-v{n}
  │        -p 127.0.0.1::3000（只有应用端口，没有工具通道）
  │        --restart unless-stopped
  │        APP_PORT / NODE_ENV=production / JWT_SECRET [/ APP_DB DB_*]
  ├─ 健康：GET /api/health 命中 "app":true（含 migrate）
  ├─ 切路由：app_access_route(DEPLOY) + Redis route:{key}.app.localhost（无 TTL）
  └─ 收尾：旧版本容器 stop（镜像保留）；超出 keep-versions 的版本清理为 PRUNED
```

### 关键设计

| 点 | 做法 | 理由 |
|---|---|---|
| 生产库 | `app_{appId}_prod`，账号同名，密码/JWT 跨版本复用 | 预览数据不进线上；重新部署/回滚不影响线上数据与登录态 |
| static 模式 | 不建库、不注入 `APP_DB/DB_*` | 纯前端没有存储依赖 |
| 部署域名 | `{deployKey}.app.localhost:8124`，deployKey 存 app 表 | 重新部署、回滚都不换地址 |
| 路由 TTL | DEPLOY 路由写 Redis 时不设过期 | 正式上线必须常驻；预览路由仍带 TTL |
| 版本 | 每次部署 `deploy_version+1`，镜像与容器都带版本号 | 镜像不可变，回滚有明确目标 |
| 回滚 | 优先 `docker start` 旧容器，宿主端口重新回读；容器被删则用同镜像+同 env 重建 | 秒级、不重建镜像、不动数据 |
| 清理 | 保留最近 5 个版本（含当前），更老的容器/镜像/快照删除，DB 记录标 PRUNED | 控制磁盘；回滚被清理的版本会明确报错 |
| 失败处理 | 健康检查/切路由失败 → 删新容器、标 FAILED，旧路由与旧容器继续服务 | 部署失败不影响线上 |

### 数据库拆分（本次拍板）

- 预览库：`app_{appId}`（原有行为，容器回收/重建时凭据可重新生成）
- 生产库：`app_{appId}_prod`（本次新增，凭据落在 `app_deploy` 行里，回滚/重建容器复用）
- 首次部署 fullstack 时生产库是**空库**，启动时由 `migrate` 按 `schema.json` 建表；预览里的测试数据不会带过去。

## 6. 已知限制 / 归属

| 限制 | 说明 | 归属 |
|---|---|---|
| 宿主重启后端口变化 | Docker 会重新分配随机宿主端口，Redis 里的 upstream 会过期 | P6 reconcile |
| 单实例锁 | `AppDeployService` 的 per-app 锁是进程内的；多实例并发部署需分布式锁 | 多实例时处理 |
| 首次部署生产库为空 | 预览数据不会迁移到线上（拆库的预期行为） | 产品约定 |
| 镜像与快照占磁盘 | 每个版本镜像实际新增约 65MB（共享 base 层）+ 快照约 68MB；默认保留 5 版 | 调 `deploy.keep-versions` / 定期 `docker builder prune` |
| 回滚不校验 schema 兼容 | 新版本若做了破坏性 schema 变更，回滚旧代码可能读不了新表 | 迁移需保持只增不改 |
| 应用删除不回收部署 | 容器/镜像/生产库/路由都还在 | P6 |
| 截图依赖 COS | 部署后异步截图，COS 未配置时只影响封面 | 既有问题 |
| 构建期 npm 兜底 | 快照缺 `node_modules` 时 Dockerfile 会 `npm ci --omit=dev`，需要网络 | 正常生成流程不会触发 |
| 生成中部署 | 有活跃生成任务时直接拒绝（避免快照复制到半份代码） | 已处理 |
| 库密码明文 | `app_deploy.db_password` 供回滚/重建容器复用，存的是明文（与容器 env 同级） | 共享环境需加密/外部密钥管理 |
