## 2. 现在的架构

```
浏览器
  ├─ 平台        http://localhost:5173   （Vue3，你本机起的 dev server）
  ├─ 预览        http://{code}.pv.localhost:8124/     → app-pv-{appId}:3000
  └─ 部署        http://{deployKey}.app.localhost:8124/ → app-dep-{appId}-v{n}:3000
                        │
                        ▼
                 proxy（独立 Spring Boot WebFlux，宿主机进程）
                   │  Host → route:{host}（Redis，1s 本地缓存）
                   │  Flux<DataBuffer> 流式转发
                   ▼
                 127.0.0.1:{随机端口}  →  app-pv-{appId}:3000（预览，带 8080 工具通道）
                                     →  app-dep-{appId}-v{n}:3000（部署，只有应用端口）
                        │
                        ├─ 预览：Express + schema.json + MySQL(app_{appId})
                        └─ 部署：不可变镜像 + MySQL(app_{appId}_prod)

主服务（8123，MVC）
  ├─ 生成任务 / 聊天 / 应用管理
  ├─ 写路由：MySQL app_access_route + Redis route:{host}
  └─ 不参与预览/部署数据通路
```

### 五个核心概念

1. **域名即路由**：`{code}.pv.localhost` 是预览地址，`{deployKey}.app.localhost` 是部署地址。应用站在 `/` 上，不剥前缀。
2. **两种模式**：`static`（纯前端，schema.tables 为空、不连库）与 `fullstack`（带存储，自动建表）。
3. **端口是派生物**：`docker run -p 127.0.0.1::3000` 随机分配，`docker port` 回读；预览带 30s 缓存，部署每次 start 后重新回读；**不是**按 appId 计算。
4. **休眠保链接**：预览容器回收时只把路由状态改成 `STOPPED`，host 保留，唤醒后地址不变。
5. **部署是版本化的**：每次部署 → 快照 + 不可变镜像 `app-dep-{appId}:v{n}` + 容器；回滚只切路由，地址不变、生产库 `app_{appId}_prod` 数据不动。

## 7. 关键决策（避免下次重新讨论）

| 决策 | 结论 | 理由 |
|---|---|---|
| 代理形态 | 独立 Maven 工程、宿主机进程、8124 | 主服务是 Servlet，无法共存 WebFlux；macOS 下宿主机进程访问不到容器 IP |
| 路由方式 | 按 Host，不是路径前缀 | 应用站在 `/`，`/api/*` 不冲突，干掉剥前缀/SPA 兜底两类 bug |
| 路由存储 | 主服务写 DB + Redis；proxy **只读 Redis** | proxy 不依赖 MySQL；主服务重启不断链 |
| 宿主端口 | 随机分配 + `docker port` 回读 | 端口段公式会撞、会耗尽；8081 已删 |
| 模式收敛 | 只有 `static` / `fullstack` | 旧三类统一 410，需重新生成 |
| 自动识别 | **关键词规则**，不调模型 | 二分类规则足够；原 AI 路由从未生效（见第 8 节） |
| 休眠 | 只改路由状态，不删域名 | 链接稳定，唤醒不需要换地址 |
| 部署容器 | 不参与回收 | 正式上线必须常驻（P5 落地） |
| 部署库 | **与预览库拆开**：`app_{appId}_prod` | 预览测试数据不进线上；重新生成/预览不影响线上数据 |
| 部署版本 | 每次部署 `v{n}`，镜像不可变，容器 `app-dep-{appId}-v{n}` | 回滚有明确目标，不需要重新构建 |
| 部署路由 | DEPLOY 路由 Redis **不设 TTL** | 正式上线常驻；预览路由仍带 TTL 回收 |
| 回滚 | 只切路由回去，生产库数据不动 | 地址稳定，用户无感 |

## 8. 本轮踩过的坑（别重复）

| 坑 | 症状 | 结论 |
|---|---|---|
| `docker exec` 不带 `-i` | 建表 SQL 静默丢弃，命令还返回 0 | 幂等初始化必须 `-i` + 回读校验 |
| MyBatis-Flex insert 显式写 null | `Column 'update_time' cannot be null` | 实体字段显式赋值，别依赖 DB 默认值 |
| 随机宿主端口 + `docker restart` | 端口从 57977 变成 58512 | 端口缓存必须带 TTL，预览前主动失效；脚本重启后要重新回读 |
| 改枚举后增量编译 | 运行时 `Unresolved compilation problem: A Switch expression should cover all possible values` | 改枚举后必须 `mvn clean compile`，否则残留坏 class |
| 文件位置与 package 不一致 | `ConflictingBeanDefinitionException`（两个同名 bean） | 包的声明必须与目录一致 |
| `spring-boot:run` 编译测试 | 过时测试导致整个服务起不来 | 改 API 后同步测试，或临时 `-Dmaven.test.skip=true` |
| shell 变量紧跟中文 | `APP_HOST�: unbound variable` | 统一写 `${VAR}` |
| LC4j 同步 ChatModel + 当前网关 | 响应体只有一个 `{`，`JsonEOFException`，路由永远静默兜底 | 别用 sync 客户端打这个网关；流式可用 |
| 并发预览 | 同一应用两条 PREVIEW 路由、两个域名 | `findPreview` 按时间倒序 + 清理重复 + `uk_app_kind` |
| `~/.m2` 在沙箱不可写 | `Operation not permitted` | proxy 用工程内 `.m2repo/`（已 gitignore） |
| `spring-boot:run` 与托管任务 | 后台任务被终止后服务就没了 | 用 `scripts/proxy-up.sh` 或独立终端起 |
