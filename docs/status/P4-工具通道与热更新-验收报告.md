## 1. 一句话结论

工具通道（8080）从"本机任意进程可写文件 / 执行命令"变为 **必须带 `X-Tool-Token`**；对话生成结束后，平台会自动让运行中的应用**重新加载代码并重启**，再通过 SSE `preview_reload` 通知前端重挂载 iframe（地址不变）。沙箱镜像已重建，真实生成任务已跑通。

---

## 2. 改了什么

### 2.1 令牌协议

```
token = hex(HMAC-SHA256(secret, appId))
secret = sandbox.tool-token-secret（默认 local-dev-tool-token-secret）
```

| 环节 | 行为 |
|---|---|
| 容器启动 | `docker run -e TOOL_TOKEN=<token>`（`SandboxContainerManager#buildEnvArgs`） |
| 主服务调用 | 所有工具通道请求带 `X-Tool-Token`（`SandboxClient#post`） |
| 容器内校验 | `sandbox/app.js` 常量时间比较；`GET /api/health` 免鉴权 |
| 未注入 token | 除健康检查外一律 `503`（fail closed，不裸奔） |
| 令牌错误/缺失 | `401` |

> secret 必须跨主服务重启稳定，否则已有容器的令牌全部失效。默认值仅用于本地开发，启动时会打 WARN；共享环境用 `SANDBOX_TOOL_TOKEN_SECRET` 覆盖。

### 2.2 新增应用控制接口（工具通道，同样要 token）

| 接口 | 行为 | 返回 |
|---|---|---|
| `POST /api/app/restart` | 停掉应用进程 → `node server.js` 重启 → 等健康 | `{stopped,pid,ready}` |
| `POST /api/app/rebuild` | `forceBuild=true` 先 `npm run build`；再 `node --check server.js`；最后重启 | `{built,checked,stopped,pid,ready}` |

实现要点：

- 停止进程不依赖 `pkill`（基础镜像不保证有 procps）：先读 `/tmp/app.pid`，再扫 `/proc/*/cmdline` 兜底；SIGTERM 等 10s，不退再 SIGKILL。
- 启动用 `spawn('node',['server.js'],{cwd:'/workspace',detached:true})`，日志追加到 `/tmp/app.log`，pid 写 `/tmp/app.pid`。
- 重启后必须命中应用通道 `"app":true` 才算成功，否则返回 `503` + 日志尾部。
- `forceBuild=false` 是生成流程的默认路径：平台 `BuildProjectTool` 已经构建过，避免重复 `npm run build`。

### 2.3 生成结束后的热更新

`GenTaskExecutor#doOnComplete`：

```
平台兜底构建通过
  → markModified（重置休眠计时）
  → sandboxClient.rebuildApp(appId, forceBuild=false)   // 语法检查 + 重启，migrate 在启动时应用新表
  → SSE preview_reload {appId, ok, message?}
  → markTaskCompleted
  → SSE done
```

- 热更新失败**不判任务失败**：代码已构建通过，用户至少保留上一版可用页面；失败原因通过 `preview_reload.ok=false` + `message` 推到前端提示。
- 沙箱未启用（本地直写）时推 `{ok:true, skipped:true}`。

### 2.4 前端 iframe 重挂载

- `ReconnectableSseClient` 新增 `preview_reload` 事件与 `onPreviewReload` 回调。
- `AppChatPage`：收到 `preview_reload` → `previewKey++`（URL 不变也重新挂载）；`ok=false` 弹 warning。
- 兜底：`done` 后若本轮没收到 `preview_reload`（SSE 断线重连场景），`updatePreview()` 后同样 `previewKey++`，用 `previewReloadedForTask` 标记避免重复加载。

## 6. 已知限制 / 后续

| 限制 | 说明 | 归属 |
|---|---|---|
| 旧容器没有 token | 镜像重建前创建的容器仍跑旧 `app.js`（不校验）；要享受鉴权需 `docker rm` 后重新预览 | 运维动作 |
| 默认密钥 | 未设 `SANDBOX_TOOL_TOKEN_SECRET` 时用内置默认值，仅适合本地 | 部署时覆盖 |
| 重建失败只告警 | 任务仍算完成，前端提示 warning | 可接受 |
| 静态模式仍建容器+空库 | 与 P4 无关，已在生成侧遗留清单 | 后续 |
| 应用删除不回收容器/库/路由 | P6 | P6 |
| 页面 `<title>` 仍是模板默认 | 生成侧遗留 | 后续 |
